# 当次招聘登录认证

仅在正在执行用户授权的招聘登录时使用本流程。不要为了测试 Skill 而读取“信息”。

## 非手机号登录：截取页面，请用户完成

先检查当前网站实际支持的登录方式。无需为了统一流程而注册新账号或强行切换短信登录；优先复用正确账号，需本人操作时按下面处理。

1. 核实当前招聘网站及其跳转的身份认证服务，保留正在使用的浏览器、标签页和会话。只截取当前页面实际显示的认证区域，例如微信或其他扫码二维码、设备确认说明、人机验证挑战、邮箱/密码登录表单。不要自行生成、解码重建、从其他会话借用二维码，也不要把截图理解成导出 Cookie、会话令牌或密码。
2. 使用当次浏览器或原生应用工具提供的截图能力，先读其文档。截图保留完整二维码及周围空白、必要的按钮/挑战内容和提示，避开无关个人资料、其他窗口及已经输入的密码。若工具无法截图，不调用仅限语音会话的屏幕工具，保持原页面可见并说明用户应操作的位置。
3. 在当前对话直接展示认证截图，附上网站/服务名称、具体动作及页面实际显示的有效期。例如“请用微信扫描这张当前登录二维码，并在手机上确认”。网站未显示有效期时不编造倒计时。密码、邮箱验证码或通行密钥需用户在原网页/设备中完成时，明确指出；普通登录表单或交互式人机验证的截图只用于指引，不能声称凭截图就能在另一台设备完成原会话登录，也不要求用户把密码发到聊天里。
4. 等待时保留该会话，不自动刷新页面或反复生成新二维码，不反复催问。页面明确显示过期、认证失败或用户主动请求时才重新获取当前认证区域；不要拿旧截图继续让用户扫码。用户尚未回来时保留进度，等其回来再生成有效截图。已发送的三分钟提醒不会因二维码刷新而重置次数。
5. 用户完成后，重新检查原页面的登录状态和账号标识；需要正常点击“已完成”等按钮时按页面提示处理。仅当确认已进入用户的正确账号后继续上传或填表。仍停留在登录页、账号不符或权限未完成时，说明实际阻碍并保留进度，不把“已扫描”当作成功。

认证截图仅用于本次用户登录。优先直接展示工具返回的图片；确需落盘时使用仓库外的私有临时目录（如 `~/Documents/Codex/job-applications/auth-tmp/`，目录 `0700`、文件 `0600`），完成、失效或取消后删除本次自行创建的临时截图。不要写入资料、投递记录网页、日志、公开仓库或分发包，也不要承诺工具/聊天系统本身的留痕已被清除。

等待本人完成上述步骤时，通知问题使用 `kind=verification`。遵守 [三分钟提醒](followup-notifications.md)：最多一条文字提醒请用户回到当前任务完成认证，不通过 IM 转发登录二维码、认证截图、密码或验证码，也不从 IM 收集认证凭据。

## 手机验证码的工具选择

先使用浏览器里确实出现的系统自动填充建议。若需查看“信息”，使用当前会话提供的原生应用控制工具；例如已提供 `mcp__cua_repl` 时，遵循其首次调用规范，通过 `cua.getApp("Messages")` 选择应用，并读返回文档后再操作。不要假设存在没有提供的 Messages MCP、AppleScript 收信 API 或浏览器短信接口。

此 Skill 不自带后台短信收集器。没有原生应用读取能力或权限时，直接请用户提供本次验证码，或在设备上完成验证。正常文字任务不要调用仅供语音会话使用的屏幕上下文工具。

## 匹配范围

- 发送请求后记录招聘服务、目标手机号尾号和发送时间；平台品牌可能是公司授权的招聘系统，先核实对应关系。
- 在应用中尽量定位相关发送者或服务名称，仅查看当前登录所需的最近消息。匹配本次请求之后收到的消息，并检查服务名称、登录用途和网站显示的有效期。消息若显示目标号码，核对尾号；不显示号码时不能凭空补充匹配依据，多号码或多请求无法区分时请用户给出当次验证码。
- 不扫描或导出短信数据库，不批量读取聊天历史、附件或其他验证码。界面偶然显示的无关消息不摘要、不复制、不保存。
- 不用其他服务的代码，不混用上一轮验证码，也不要在聊天回复中复述完整验证码。只将匹配代码填入当前已核实的招聘网站。
- 无法找到可确认匹配的代码时，请用户提供本次代码；不靠不断重发短信碰运气。确需重发时遵守网站倒计时，每轮最多补发一次，重置时间窗口；仍失败就说明具体阻碍并由用户完成。

## 边界与结果

macOS 访问授权、iPhone 与 Mac 消息同步、网页系统填充都可能影响结果。这些条件只有实际登录时才能验证；工具存在不代表已经能读到短信。

不要更改系统权限、登录 Apple ID、修改安全设置或绕过 CAPTCHA 来强行完成。可告知用户具体界面要求并保留当前进度。验证成功以页面确实进入正确账号为准，不以验证码已填入为准。

验证码仅短暂用于认证，不主动写入资料、日志、脚本、输出文件或打包产物；不要承诺浏览器、聊天系统或工具本身绝不留痕。
